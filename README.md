# get-mtg-card-images-sample
MTGのcard-image-galleryから、Selenium(ChromeDriver)でカード画像を一括ダウンロードするサンプルPython
- サンプルのiniファイルはアバター用
  - https://magic.wizards.com/ja/products/avatar-the-last-airbender/card-image-gallery

# 必要なもの
- ChromeDriver
  - https://developer.chrome.com/docs/chromedriver/downloads?hl=ja
- Pythonライブラリ
  - Selenium
  - BeautifulSoup
  - PIL
